# CI ciblée et gate complet

Politique propriétaire du14nov2026. Une Draft PR sans label `ci:full` produit le job API **development** : lint/format/pipcheck/contrats, tous tests frontend/build et backend sélectionné par `ops/ci_selection.py`. Coutures explicites HTTP/private/public/frontend-browser et tests backend ajoutés/modifiés ; runtime/config/migration/dépendance/conftest inconnus =>fallback full. Docs-only =>aucun backend, explicitement annoncé. Aucun shell/xargs issu du texte de PR ou nom de fichier ; argv Python vérifié. Le job YAML reste ID integrated, son nom API change selon le mode ; même garde source/head début/fin.

PR nonDraft, label **ci:full** ou push main =>job API **integrated** exécutant toute la suite originale (backend, fixtures migrations, navigateur compilé, frontend, contrats). Le Coordinator ajoute ci:full au SHA final avant ready/merge et exige integrated completed/success sur ce SHA dans le run courant. Development vert, même avec fallback backend full, ne vaut jamais gate fusion. Label conservé pendant corrections pour rester full. Événements labeled/unlabeled/ready_for_review/converted_to_draft relancent au même head ; aucune utilisation pull_request_target, nouveaux secrets/scopes/cron/deploy ou skipci.

Résumés : mode/SHA/selection/statut ; preuves synthétiques connues seulement sur failure, PNG réguliers non symlinks et JUnit, rétention1jour. Inconnue de sélection échoue ou retombe full, jamais sélection silencieusement vide. Tests purs de la sélection vérifient docs-only, coutures, fallback, fichiers manquants et gate intégral ; CI réelle valide aussi le YAML. Sources primaires GitHub consultées14nov : [événements pull_request](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#pull_request), [contains et labels](https://docs.github.com/en/actions/reference/workflows-and-actions/expressions#contains). Rapport Developer/Tester compact : commandes, comptes, échecs réels, risque restant ; pas campagne locale entière répétée sans changement pertinent.
